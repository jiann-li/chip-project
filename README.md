# CHIP Project Page

Official project page for the **SIGGRAPH Asia 2026 Conference Paper**, **CHIP: Unifying Physics-Based Humanoid Interaction with a Context-Conditioned Interaction Prior**.

The site is a dependency-free static build with an interactive five-stage hero sequence, paper overview, method pipeline, qualitative behaviors, quantitative results, responsive layouts, and a BibTeX citation.

## Preview locally

From this directory, start any static file server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize before publishing

- Replace the disabled **Code** button in `index.html` when the repository is public.
- Swap images in `assets/` while preserving the existing filenames to keep the layout unchanged.

The template can be deployed directly with GitHub Pages—no build command is required.
